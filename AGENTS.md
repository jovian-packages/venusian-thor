# Agent guidance — jovian/venusian-thor

1. **What it is:** the `thorvg` rasterization and painting drivers for Venusian Topside, on ext-thorvg. `ThorVGRasterizationDriver` + `ThorVGScanner`, and `ThorVGPaintingDriver` (a `BrushPaintingDriver`) + `ThorVGBrush`, both registered by `VenusianThorServiceProvider`. `ThorVGSurface` is the one place ThorVG is called: one canvas and one shape over a framebuffer's memory or a scratch buffer.
2. **Tiers:** `ThorVGScanner` is `Scanner` (`path()`), `MaskScanner` (`mask()` for PATH ops) and `DirectScanner` (`fill()` in place). VelvetGE's `DirectDraw` picks: in place when `drawsInto()` (32-bit B G R A or R G B A rows, top first, stride a multiple of 4, little-endian host), masks through the store's `paintMasks()` otherwise. Curves, pixel work and batches come from VelvetGE through `CompletingScanner`. Hard edges are VelvetGE's whole (the driver hands back `CLandScanner` or `PHPLandScanner`).
3. **Measured facts the code depends on (do not change without re-measuring):** `TVG_ENGINE_OPTION_NONE` (the default option clears redrawn regions and erases earlier shapes on a reused canvas); premultiplied colorspaces `ARGB8888` (B G R A bytes) and `ABGR8888` (R G B A bytes), never the "S" ones (they unpremultiply the whole buffer after each draw); the viewport is the clip and can only be set while the canvas is synced; a four-point contour gets a fifth point (`ThorVGScanner::trace()`) so ThorVG's whole-pixel rectangle fast track (`_axisAlignedRect`, five path commands) never applies.
4. **In place equals VelvetGE's blend:** premultiplied source-over on the stored bytes is colour·a + pixel·(1 − a), alpha a + pixelAlpha·(1 − a), which is VelvetGE's formula. So it is right on frames with any alpha. `ThorVGSurface::BLEND` = 5 is the measured worst per byte for one shape; overlapping shapes accumulate.
5. **Brush:** `ThorVGBrush` takes anti-aliased `path`, `gradpath`, `polyline`, `ellipse`, `ring`, `roundrect`, `roundring`. Shapes go through `Rasterizer::lower()` and are rebuilt as ThorVG paths. Gradients are ThorVG's: the command's 256-colour ramp as 256 stops, a unit line or circle, and the inverse of the command's matrix as the gradient transform; `takes()` refuses a gradient whose matrix has no inverse. `ThorVGBrush::TOLERANCE` = 40.
6. **Damage:** `fill()` and the brush answer a shape's extents inside the clip, a superset of the pixels changed. Topside's DirectDraw matrix asserts equal damage on its fixed shapes and passes; a sliver shape would not be equal.
7. **Testing:** the tests run inside topside's suite. Workbench: a local clone of venusian/topside at its committed HEAD (not a symlink to the live tree) with its `vendor/` copied in; a bootstrap file named in `phpunit.xml` that requires `vendor/autoload.php` and autoloads `Jovian\Rendering\Thor\` from this package's `src/`; at the end of `tests/Pest.php`, after a `require_once` of that bootstrap: `LibraryDrivers::$rasterization['thorvg'] = new ThorVGRasterizationDriver();` and `Tolerance::$by['thorvg'] = ThorVGSurface::BLEND;`. Copy `tests/ThorVGParityTest.php` into `tests/Rasterization/` and `tests/ThorVGBrushTest.php` into `tests/Painting/`. Run the whole suite on both PHPs and with `TOPSIDE_STROKER=ext` (2026-11-13, topside e4139a4 plus the `Tolerance::named()` test change: 3525 passed, 6 skipped, all three).
8. **House rules:** plain technical English; version line follows venusian/framework (0.11.x); commit finished work; no window or sound without asking.
